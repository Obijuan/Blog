Voy a continuar con la tradicción de hacer **un blog** en el que
ir contando las cosas que hago, y que pruebo. El objetivo es recordar las
cosas, para que no se me olviden, y consultarlas en el futuro

Este blog está creado como **páginas estáticas** escritas en 
makdown, en este repositorio de github: [Blog](https://github.com/Obijuan/Blog)

Estoy utilizando **github-pages**. Para convertir los ficheros markdown
en html/css estoy usando [zola](https://www.getzola.org/). Es un generador de
páginas estáticas escrito en **RUST**. Esto permite tener sólo un ejecutable
que lo hace todo. Es muy fácil de instalar

Desde **Ubuntu 24.04** lo he instalado con este comando

```bash
sudo snap install zola --edge
```

La versión que se me ha instalado es la **0.22.1**

```bash
obijuan@JANEL:~$ zola --version
zola 0.22.1
obijuan@JANEL:~$
```

El tema que he elegido, de momento, es [Terminimal](https://github.com/pawroman/zola-theme-terminimal)
